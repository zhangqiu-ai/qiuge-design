## 問題

已有模型工作區中，如何加入新的 HuggingFace 模型而不離開目前任務？

## 做法

- 中央保留所選模型與任務，新增自訂模型時在其上開啟對話框。
- 對話框先提供模型分類、搜尋框與結果卡，再列 Repo ID、可選檔案篩選、自訂名稱及模型任務型態。
- 切換候選後，結果卡顯示 MiniMax 等模型；選取項目時，下方 Repo ID 與自訂名稱帶入對應內容，底部保留取消及主要加入動作。
- 圖片只保留模型標頭及對話框；移除後方提示詞、執行日誌與憑證欄位內容。

## 為什麼有效（推論）

搜尋與手動輸入共用面板，可能讓新手從候選開始，也讓進階使用者指定 Repo 與檔案。

## 借鑑要點

- **適合**：模型或外掛匯入，需要搜尋及手動路徑的桌面工具。
- **不適合**：未顯示失敗、權限與容量資訊就直接套用到高風險安裝。
- **移植時注意**：補齊錯誤、下載進度、取消及憑證保護；畫面中的模型數字與算力不作效能結論。
